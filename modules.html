Box Rush 产品模块图BOXラッシュ

日本市场的 TCG 众筹开卡平台（Web）。下面是目前拆出的全部模块和功能点，实心点是 MVP 要做的，其余按阶段推进。

MVP P1 · 验证后首批 P2 · 规模化后 明确不做 可验证信任相关功能

一场开盒怎么走完（场次主流程）

  1. 1创建场次商家 · 不变量校验
  2. 2入仓验封运营 · 入仓后才能开售
  3. 3审核 + 种子承诺运营 / 系统
  4. 4售位用户 · 满员才开
  5. 5分位公示系统 · 开盒前公布
  6. 6集中开盒 + 录像运营 · 平台相机
  7. 7归属 + 开盒记录系统 / 运营
  8. 8寄存 · 合单发货运营 → 用户

平台服务层（所有模块的底座）

随机和录像只由这一层执行，商家和自营团队都没有调用权限。

明确不做

  • 充值点数、站内余额、提现
  • 回收 / 卖回平台 / ポイント変換
  • 刮卡等平台生成随机的小游戏
  • 按消费额计、每月重置的会员等级
  • 直播打赏；原生 App（只做 Web）
  • 商城（密封盒 / 单卡直售）
  • 年龄验证、未成年人专项功能

参考来源

  • 功能参考 HOBBY STOCKS（中国大陆拆卡 App）
  • 前端参考 DOPA（日本 Oripa 头部），只借界面，不借机制
  • 支付走第三方聚合，首选 Stripe
  • 分队单元从"球队"换成キャラクター枠；开盒从商家自播换成平台集中开盒

MVP 要回答的问题

  • m：用户愿意为"可验证开封"多付多少
  • k：平均每次发货能合并几位（低于 3 模式不成立）
  • MVP 自营 + 集中开盒 + 集中仓，先不做直播
